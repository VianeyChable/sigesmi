# SIGESMI
### Sistema de Gestión de Servicios y Mantenimiento Informático

Sistema desarrollado en PHP y MySQL para la gestión de solicitudes de servicios técnicos, equipos, áreas y evidencias.

**Autora:** Vianey Chable
**Tecnologías:** PHP, MySQL, HTML, CSS, JavaScript, WampServer

### Funcionalidades
- Login de usuarios
- Gestión de áreas y equipos
- Registro de servicios
- Carga de evidencias
- Reportes y gestión de solicitantes y técnicos

### Instalación
1. Clonar repositorio
2. Importar base de datos
3. Configurar conexion.php
4. Ejecutar en WampServer / XAMPP

Repositorio: https://github.com/VianeyChable/sigesmi
